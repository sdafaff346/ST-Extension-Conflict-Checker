# 확장 충돌 검사기 (Extension Conflict Checker)

설치하려는 확장의 GitHub 링크를 넣으면 지금 설치된 확장들과 코드를 비교해 충돌 가능성을 알려줍니다. 설치된 확장끼리 전체 검사도 됩니다.

## 설치
1. SillyTavern의 확장(Extensions) 패널 → **확장 설치(Install extension)**
2. 아래 주소를 붙여 넣고 설치
   `https://github.com/sdafaff346/ST-Extension-Conflict-Checker`
3. 업데이트는 확장 패널의 업데이트 버튼으로 받을 수 있어요.

## 사용
- 패널에 링크 입력 → **링크 검사** / **설치된 확장 전체 검사**
- 슬래시 명령: `/extconflict` , `/extconflict https://github.com/작성자/확장`

## 검사 항목
| 등급 | 내용 |
|---|---|
| 위험 | 같은 슬래시 명령·매크로·함수 도구·인터셉터 이름, 같은 window 전역 변수, 같은 extension_settings 키, 같은 HTML id, 중복 설치, ST 버전 부족, 의존 확장 없음 |
| 주의 | 같은 대상 몽키패치(fetch, $.fn 등), 같은 단축키, CSS !important 겹침, 이벤트 맨앞/맨뒤 경쟁 |
| 참고 | 둘 다 프롬프트 가로채기, 이미 설치된 같은 확장(버전 비교), 공통 이벤트 다수 |

## AI 검토 (선택)
결과 창의 **AI로 진짜 충돌인지 검토** 버튼을 누르면, 걸린 항목 주변 코드 조각만(최대 15건, 약 3만 자) API로 보내 다음을 받아요.
- 항목별 판정: 충돌 확실 / 가능성 높음 / 문제 적음 / 오탐
- 쉬운 설명과 해결 방법
- 정규식이 놓친 충돌 (예: 둘 다 같은 이벤트에서 메시지를 고침)

설정의 "AI 검토에 쓸 연결"에서 연결 프로필을 고르면 그 프로필의 API·모델·키·프록시로 **검토 프롬프트만** 보내요. 프리셋, 캐릭터 카드, 채팅 내용은 들어가지 않아요. 검토 프롬프트는 설정에서 직접 고칠 수 있고, 결과를 읽는 데 필요한 JSON 형식 안내만 자동으로 뒤에 붙어요. 프로필 프리셋의 온도 같은 값을 쓰고 싶으면 "프리셋 설정도 적용"을 켜세요. 처음 한 번 전송 동의를 물어봐요.

코드를 읽어서 찾는 "가능성" 검사라 압축(번들)된 확장은 일부를 놓칠 수 있고, 표시돼도 실제로는 괜찮을 수 있어요.
링크 검사는 GitHub(raw.githubusercontent.com, api.github.com)에 접속합니다.
